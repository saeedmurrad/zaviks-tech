Services

Change it, install it, then keep it.

The shelf gets you a head start. The work after that is where the product becomes yours.

01

Customise

Brand, colours, names, and the words a user reads live in configuration. They are not painted into the code, so a second customer does not require a second product.

Features are modular. We can add one, or switch one off, without unpicking the rest. You describe the change, attach whatever explains it, and we send a quote and a timeline before any of that work starts.

02

Deploy

Each customer gets their own copy. We install it on your server or on a cloud account you control. The package is the same each time, with a short setup guide: what it does, the stack, the environment variables, and how the brand and settings are changed.

Products that need a repeatable install are packaged with Docker, so a machine you already run and a cloud account are approached the same way.

03

Maintain

We record which version you are on, where it is deployed, and when it went live. Security updates and bug fixes are applied to that copy. Every support request is logged against your business and the product, so the history is not trapped in an inbox.

Plans start when the system is live. Basic, Standard, and Premium are described on the pricing page. The right one is part of the quote, not a surprise later.
